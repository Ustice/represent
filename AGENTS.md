# Represent

The core owns framework-neutral schemas, representations, conversions,
operations, and their graph. Adapters own target-specific semantics, including
interpretation of opaque metadata. Algebra supports the guarantees; ordinary
APIs use approachable engineering language.

There are no development-phase gates or prescribed design/test/code sequence.
Document project-specific decisions and exceptions; omit instructions that
merely restate normal engineering practice. Add process only when experience
shows a need.

# Triage labels

Engineering skills use five canonical triage roles. This table maps those roles
to the labels configured in the GitHub repository.

| Canonical role    | GitHub label      | Meaning                                   |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue    |
| `needs-info`      | `needs-info`      | Waiting for more information              |
| `ready-for-agent` | `ready-for-agent` | Scoped and ready for agent work           |
| `ready-for-human` | `ready-for-human` | Requires human judgment or implementation |
| `wontfix`         | `wontfix`         | Will not be actioned                      |

When a skill refers to a canonical role, use the corresponding GitHub label. Use
these labels when triaging issues. They are not prerequisites for direct work
and do not override the current phase or specifications.

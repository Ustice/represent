# Former development phases

The staged development model is retired by
[Work from feedback](decisions/0006-work-from-feedback.md). There is no current
phase or phase-transition gate. Design, implementation, and testing can proceed
together under [AGENTS.md](../AGENTS.md).

Represent remains experimental, without a stable API or compatibility promise.
Removing the stages does not declare the existing code production-ready.

[ADR 0002](decisions/0002-development-phases.md) describes the former model;
[ADR 0003](decisions/0003-enter-phase-minus-1.md) records the historical move
into design work. Those records explain past choices, not current permission.

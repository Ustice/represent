# Contributing

Read [AGENTS.md](AGENTS.md) for the project boundaries and
[docs/workflow.md](docs/workflow.md) for how we work. Both apply to people and
agents. Read additional design documents as the task requires.

Use Node.js 26 and pnpm, as described in the [README](README.md#development).
Run `pnpm check` before handoff; CI runs the same gate.

An issue is useful for work that needs tracking or discussion, but is not a
prerequisite for a small change. A pull request should explain the outcome,
validation, and any material limitations. Link relevant issues and specification
clauses without creating extra artifacts just to complete a template.
